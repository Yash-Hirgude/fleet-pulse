# Fleet Pulse — Real-Time Ops Dashboard

A high-throughput, fault-tolerant monitoring console for 2,000 microservices built with Angular 21+ and a chaos-injected Node.js mock backend.

## Structure
- `/frontend`: Angular 21+ application (Signals, RxJS, Angular Material).
- `/backend`: Node.js mock backend and chaos switchboard.
